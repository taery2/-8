## Задание
Размен сумм до 150 монетами `{1,6,9}`. Жадный критерий 1 — наибольший номинал; критерий 2 — наименьший номинал. Эталон — ДП. Дополнение Ж4 — зависимость среднего отклонения от N=5,10,20,40,80.

Проведено 300 случайных испытаний. Отклонение: `(greedy_count-optimal_count)/optimal_count*100%`.

| Критерий | Среднее, % | Медиана, % | Максимум, % | Совпадение с оптимумом |
|---|---:|---:|---:|---:|
| Наибольший номинал | 7.93 | 0.00 | 100.00 | 68.0% |
| Наименьший номинал | 643.13 | 692.31 | 800.00 | 3.3% |
## Контрпример
Для S=12 жадный алгоритм максимального номинала берёт `9+1+1+1` — 4 монеты. Оптимальное решение `6+6` — 2 монеты. Следовательно, критерий максимального номинала не оптимален.

## Дополнительное задание Ж4
В методичке Ж4 просит менять N, но задача размена варианта 4 не содержит параметра количества предметов N. Поэтому N интерпретирован как число случайных сумм в выборке, по которой оценивается среднее отклонение. Это оговорённая адаптация дополнительного задания, а не изменение математической размерности размена.

| N (число тестовых сумм) | Среднее отклонение, % |
|---:|---:|
| 5 | 13.33 |
| 10 | 2.97 |
| 20 | 11.56 |
| 40 | 8.22 |
| 80 | 6.96 |
## Вывод
Для системы `{1,6,9}` жадное правило максимального номинала не гарантирует минимум монет. ДП даёт точный ответ за `Θ(kS)`, жадный алгоритм быстрее, но может ошибаться.
